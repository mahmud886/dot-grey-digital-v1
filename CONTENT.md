# Editing the site's content

> **বাংলায় সংক্ষেপে:** সাইটের সব লেখা `src/content/*.json` আর `src/site/agency.ts` ফাইলে আছে — এগুলো বদলালেই পেজ বদলে যাবে, কোড ছুঁতে হবে না।

Almost every word on the site lives in a handful of data files. Edit the file, run `npm run build` (or just push and let Vercel build), and every page that uses it updates. You should not need to touch any component to change copy.

After any edit, run `npm run lint && npx tsc --noEmit` — TypeScript will tell you if a field is missing or misspelled.

## Where each piece of content lives

| File | What it drives | Notes |
| --- | --- | --- |
| `src/content/site.json` | Studio name, tagline, description, email, founding year, office addresses, contact-form budget and timeline options | The single source for contact details. There is deliberately no phone number or social links field — add them here (and to `src/data/site.ts`) only when real ones exist. |
| `src/content/works.json` | Work index, homepage reel and grid, every case study, industries page, related work | One entry per project. See "Add a project" below. |
| `src/content/team.json` | About page people, `/team/[slug]` pages, article bylines | `socials` is an empty list until real profile links exist; links of `#` are hidden automatically. |
| `src/content/insights.json` | `/insights`, articles, homepage "Notes.", resources page | Articles are blocks (paragraph, heading, quote, list), not markdown. |
| `src/content/jobs.json` | `/careers`, job pages, benefits | |
| `src/content/faq.json` | `/faq`, homepage FAQ, service-page questions | Keep the `category` values matching the `categories` list. |
| `src/content/values.json` | About and culture pages | |
| `src/content/stats.json` | Numbers on the homepage and about page | **Check these are true** before relying on them. |
| `src/content/testimonials.json` | Homepage quotes | Only use quotes you have permission to publish. |
| `src/content/pages/legal.json` | `/privacy` and `/terms` | Update the `updated` date whenever you change them. |
| `src/site/content.ts` | The six services (titles, one-liners, capabilities, tools) and the five process steps | |
| `src/site/agency.ts` | Process stages, engagement models and starting prices, start-wizard options, industries, tool principles, AI page, culture rituals, resource checklists, accessibility and cookie statements | Prices are shown as "indicative starting point — not a quote". |

The `src/data/*.ts` files are thin typed wrappers around the JSON. Only edit them when you add or remove a field.

## Common jobs

**Add a project.** Copy an existing entry in `works.json`, give it a new unique `slug` (that becomes `/work/<slug>`), and fill every field. `category` must be one of `UI/UX`, `Web`, `Email`, `Branding`. `stats` are the numbers shown on cards and in "Outcomes." — use real ones. The first six projects in the file appear in the homepage reel. To show it on the industries page, add its slug to a sector in `src/site/agency.ts`.

**Add real project screenshots.** Projects currently show coded "concept visual" mockups (`src/site/shared/ProjectMockup.tsx`, text in `src/site/shared/mockups.ts`). To use real images: put them in `public/work/<slug>/` (e.g. `cover.jpg`, `1.jpg`…), then in the card and case-study components replace `<ProjectMockup … />` with `next/image` pointing at those files. Keep images around 2400px wide, JPEG or WebP.

**Add an article.** Add an entry to `posts` in `insights.json`: a unique `slug`, `category` (from `categories`), `date` (`YYYY-MM-DD`), `readingMinutes`, `author` (a team member's slug), `excerpt`, and `blocks`.

**Add a job.** Add an entry to `jobs` in `jobs.json` with a unique `slug`. Applications go to the studio email.

**Add or change a team member.** Edit `team.json`. The `slug` becomes `/team/<slug>` and is used for article bylines, so update `author` fields in `insights.json` if you rename one. Portraits are generated artwork; to use real photos, put them in `public/team/<slug>.jpg` and swap the `Portrait` component in `src/site/Bits.tsx` for `next/image`.

**Change prices.** Edit `from` (and `pricing`) on each engagement in `src/site/agency.ts`.

## SEO

- **Page titles and descriptions** are set at the top of each page file in `src/app/(site)/**/page.tsx` through `pageMeta({ title, description, path })` (`src/site/meta.ts`). Dynamic pages (case studies, services, articles, jobs, people) build theirs from the content files.
- **Site-wide defaults** (title template, default description, share image) are in `src/app/layout.tsx` and `src/app/opengraph-image.tsx`.
- **`sitemap.xml`** is generated by `src/app/sitemap.ts` from the same content files, so new projects, articles and jobs appear automatically.
- **The site address** comes from `src/lib/site-url.ts` (the Vercel production URL, falling back to `https://dotgreydigital.com`).

## Forms

The contact form, the start-a-project steps and the newsletter field open the visitor's email app with their answers filled in, addressed to the email in `site.json`. Nothing is stored on the site. To receive submissions directly instead, connect an email service (for example Resend) and replace the mailto hand-off in `src/site/Pages.tsx` and `src/site/More.tsx`.
